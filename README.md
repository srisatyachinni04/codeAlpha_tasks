# CodeAlpha Internship Tasks

This repository contains my projects completed as part of the **CodeAlpha Internship**. These tasks helped me develop practical skills in Python programming, data analysis, data visualization, and web scraping.

## 📂 Projects

### 1. Exploratory Data Analysis (EDA)

**File:** `codeAlpha_EDA.ipynb`

**Description:**  
Performed Exploratory Data Analysis on a sales dataset to understand sales performance, customer patterns, product categories, regional trends, and data quality.

**Key Activities:**
- Loaded and explored the sales dataset using Pandas and NumPy.
- Checked missing values, duplicate records, and potential outliers.
- Analyzed sales and profit by product category, region, and state.
- Visualized data using Matplotlib and Seaborn.
- Examined correlations between quantity, sales, unit price, and profit.
- Analyzed yearly and monthly sales trends.
- Identified potential data quality issues.

**Libraries Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 2. Web Scraping

**File:** `codec_task webscraping.ipynb`

**Description:**  
Performed web scraping on [Books to Scrape](https://books.toscrape.com/) to extract book information and organize it into a structured dataset.

**Key Activities:**
- Sent HTTP requests using the Requests library.
- Parsed HTML content using BeautifulSoup.
- Extracted book titles, prices, ratings, and availability.
- Stored the extracted information in a Pandas DataFrame.
- Exported the collected data into a CSV file named `books_dataset.csv`.

**Libraries Used:**
- Python
- Requests
- BeautifulSoup
- Pandas
